# Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the runnable foundation and Milestone 1 design system and responsive application shell without implementing later product milestones.

**Architecture:** React Router owns the six route boundaries inside a responsive `AppShell`. Focused UI primitives expose consistent styling through small variant APIs, while route pages reuse a single placeholder presentation. Tailwind CSS supplies project tokens and responsive layout; no product state or persistence is introduced.

**Tech Stack:** React, Vite, JavaScript, Tailwind CSS, React Router, Lucide React, Dexie.js, vite-plugin-pwa, Vitest, Testing Library

**Spec:** `docs/superpowers/specs/2026-08-28-milestone-1-design.md`

## Global Constraints

- Implement Milestone 1 only; exclude Dashboard content and all learning, persistence, quiz, and review logic.
- Use the exact warm palette and Geist/Noto Sans JP typography from `AGENTS.md`.
- Keep components focused, semantic, keyboard accessible, and responsive.
- Do not introduce authentication, backend services, external APIs, or complex state management.
